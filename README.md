# 🎂 Shabnam Birthday Website

A beautiful and interactive birthday celebration website created for **Shabnam**. This project delivers a personalized birthday experience with animations, music, visual effects, and heartfelt messages.

## ✨ Features

* 🎉 Interactive birthday celebration page
* 🎈 Animated balloons and decorative effects
* 🎂 Birthday cake and celebration elements
* 🎵 Background birthday music
* 💌 Personalized birthday wishes and messages
* 📱 Responsive design for desktop and mobile devices
* ⚡ Lightweight and fast-loading website

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* jQuery

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/tanvirm01/shabnam-birthday.git
```

### Navigate to the Project Directory

```bash
cd shabnam-birthday
```

### Run Locally

Simply open the `index.html` file in your browser.

Or start a local server:

Using Python:

```bash
python -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## 🎨 Customization

You can personalize the website by modifying:

* Recipient name
* Birthday messages
* Images
* Music files
* Colors and animations

Update the relevant content inside:

* `index.html`
* `effect.js`
* `stylesheet.css`
